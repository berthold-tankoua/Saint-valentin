💖 Valentine Web Card

Une petite page web interactive créée en HTML, CSS et JavaScript pour proposer la Saint-Valentin de façon originale.
Animation de cœurs, boutons interactifs, mini-jeu avec checklist et cadeau caché téléchargeable : un projet simple, fun et responsive.

✨ Fonctionnalités

💌 Carte interactive Valentine

❤️ Animation de cœurs dynamiques

🎮 Mini-jeu checklist avec progression

💾 Sauvegarde automatique (localStorage)

🎁 Cadeau caché téléchargeable

📱 Responsive (mobile, tablette, desktop)
